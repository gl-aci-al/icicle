## Features

### Make X yours

- **Username & profile picture masking** — Mask usernames and profile pictures.
- **Custom accent colors** — Change X's accent color.
- **Bring back the bird** — Restore the Twitter logo.
- **FXEmbed links** — Copy links through FXEmbed instances.
- **Account information** — Access account information through the account dropdown.

### Hide on X

Get rid of the interface elements you don't want.

- **Premium promotions** — Hide the Subscribe to Premium card.
- **Trending Now** — Hide the Trending sidebar card.
- **Who to Follow** — Hide suggested accounts.
- **Footer links** — Hide footer navigation and links.
- **Chat drawer button** — Hide the floating chat drawer button independently of the Chat sidebar link.
- **Grok buttons** — Hide the Grok corner button and Grok actions on posts.
- **Live on X** — Hide the Live on X Spaces card.

### Sidebar customization

Individually hide whichever sidebar items you don't need.

- X logo
- Home
- Explore
- Notifications
- Chat
- Calls
- Grok
- History
- Creator Studio
- Premium
- Profile
- More
- Post button

### Post blockers

- **Paid partnerships** — Hide posts labeled by X or their authors as paid partnerships.
- **AI-generated posts** — Hide posts labeled as AI-generated by X or their authors. False positives are possible.

### Word blocklist

Filter content using words, phrases, or regular expressions. One entry per line, matched without regard to capitalization.

**Matching options**

- Match entries against authors' usernames and display names.
- Enable JavaScript regular expressions for more advanced filters.
- Detect common leetspeak substitutions.
- Detect words split by inserted spaces or punctuation.
- Detect Greek and Cyrillic characters that resemble Latin letters.
- Normalize Unicode compatibility and fancy-font characters.
- Collapse repeated characters to catch stretched words.
- Flag unusual Unicode characters, including invisible, directional, and combining characters.

**Choose what happens to matching posts**

- **Warn / Blur** — Blur the post, show the reason it matched, and provide a button to reveal it.
- **Remove** — Hide the matching post entirely.

**Media controls**

- Blur images and videos until clicked to reveal.
- Whitelist usernames, with or without the `@` prefix.
- Configure whether whitelisted accounts bypass media blurring too.

### Import & export

- Export and import settings.
- Export and import word blocklists.
- Optionally include the author's name and list name in exported JSON files.

## AI transparency

Yes, AI has helped build Icicle.

A substantial portion of the code has been AI-assisted. I could not realistically have written every line by hand, but that doesn't mean the project was generated in one shot and shipped without thought.

AI tools have been used as coding aids. The feature ideas, product direction, requirements, and decisions about what Icicle should do are still mine.

I'm being transparent about that because I think it's better to explain how AI was used than to pretend it wasn't involved.

More about the project and my approach to AI-assisted development is available on the [About page](https://site.gl.aci.al/icicle/about).
