Install Icicle

Icicle is currently available for Chromium-based browsers only. Firefox support is not available yet. Follow the steps below to install it.

Chrome, Edge, Brave, or Opera

  1. Download Icicle

    Grab the latest build from the download page.

  2. Unzip the download

    If the file arrives as a .zip, extract it to a folder you can find again.

  3. Open your extensions

    Go to chrome://extensions in your browser.

  4. Turn on Developer mode

    Use the toggle in the top right corner of the extensions page.

  5. Load the extension

    Click Load unpacked and select the Icicle folder you extracted.

  6. Pin it and open X

    Pin Icicle from the toolbar, open x.com, and set up your filters.

Firefox is not supported yet. When a Firefox build is ready, it will be listed on the download page.
