Install Icicle

Icicle supports Chromium-based browsers and Firefox desktop. Firefox support is experimental and may have bugs.

Chrome, Edge, Brave, or Opera

  1. Download Icicle

    Grab the latest build from the download page.

  2. Unzip the download

    If the file arrives as a .zip, extract it to a folder you can find again.

  3. Open your extensions

    Go to chrome://extensions in your browser.

  4. Turn on Developer mode

    Use the toggle in the top right corner of the extensions page.

  5. Load the extension

    Click Load unpacked and select the Icicle folder you extracted.

  6. Pin it and open X

    Pin Icicle from the toolbar, open x.com, and set up your filters.

Firefox desktop (experimental)

Firefox uses the same download, with no build step. Until a signed Firefox add-on is available, this is a temporary install that Firefox removes when it closes.

  1. Download and unzip Icicle

    Get Icicle from the download page and extract the archive.

  2. Open Firefox debugging

    Open about:debugging#/runtime/this-firefox in Firefox.

  3. Load Icicle

    Choose Load Temporary Add-on and select manifest.json in the extracted folder.

  4. Open X

    Open x.com and set up your filters.
